## 式を型で表す

命題論理の式は変数・⊥・否定・2 項の結合という有限個の作り方で組み立てられます。Haskell ではそのまま再帰的なデータ型になります。

```haskell
data Prop
  = Var Char
  | Bot
  | Not Prop
  | And Prop Prop
  | Or  Prop Prop
  | Imp Prop Prop
  deriving (Eq, Ord, Show)
```

Hutton の第 8 章にある `Prop` に、`Or` と `Bot` を足したものです。`deriving (Eq, Ord)` が付いているのは、式どうしを比べたり(推論規則の「同じ式か」の判定)、`Data.Set` に入れたり(探索の訪問済み)するためです。

## 前置記法で読み書きする

ファイルと JavaScript との間では、式を `>p!q`(p→¬q)のような前置記法の文字列で受け渡します。前置記法には括弧が要りません。先頭の 1 文字を見れば「何個の引数を続けて読むか」が決まるからです。

```haskell
parsePrefix :: String -> Maybe (Prop, String)
parsePrefix ('F' : rest) = Just (Bot, rest)
parsePrefix (c : rest)
  | c `elem` "pqr" = Just (Var c, rest)
parsePrefix ('!' : rest) = do
  (a, rest') <- parsePrefix rest
  return (Not a, rest')
parsePrefix (c : rest)
  | c `elem` "&|>" = do
      (a, rest1) <- parsePrefix rest
      (b, rest2) <- parsePrefix rest1
      return (binary c a b, rest2)
parsePrefix _ = Nothing
```

読めた式と「残りの文字列」の組を返し、2 項の結合子では 1 つ目を読んだ残りから 2 つ目を読みます。`do` 記法は `Maybe` モナドのもので、途中で `Nothing`(読めない)が出たら全体が `Nothing` になります。第 12 章で習う内容ですが、ここでは「失敗したら止まる連鎖」と読めば十分です。

逆向きの `toPrefix` は単純な再帰で、`parse (toPrefix p) == Just p` が成り立ちます。この往復は `test/Spec.hs` で確かめています。

## 画面用の表示

`pretty` は infix に直します。括弧を付けるのは「2 項の式の中にある 2 項の式」だけで、変数・⊥・否定には付けません。`¬(p∧q)` の括弧は、否定の中が 2 項だからです。

```haskell
pretty (Imp a b) = operand a ++ "→" ++ operand b

operand a
  | isBinary a = "(" ++ pretty a ++ ")"
  | otherwise  = pretty a
```

JavaScript 側の `pretty` も同じ規則で書き、Haskell が書き出した 37 件の例と一致することを検査しています。

## 真理値と充足可能性

第 8 章のトートロジー検査器と同じ作りです。割り当て `Subst` は変数と真偽の連想リスト、`eval` は割り当てのもとで式を評価します。含意は `eval s a <= eval s b` と書けます。`False <= True` が真になるので、「前件が偽か後件が真」の意味になります。

```haskell
sat :: [Prop] -> Bool
sat ps = any (\s -> all (eval s) ps) (substs ps)

unsat2 :: Prop -> Prop -> Bool
unsat2 a b = not (sat [a, b])
```

`substs` は式の集合に現れる変数すべてへの割り当てを全部作ります。変数は 3 つまでなので、割り当ては多くても 8 通りで、総当たりで十分です。`unsat2 a b` が真なら、a と b を同時に真にする割り当てが無い、つまり「2 つ合わせると矛盾する」ということで、これが REFUTE の「消せる Pair」の条件です。

例を挙げます。`p→q` と `p∧¬q` は、p を真にすると q が真かつ偽になり、p を偽にすると `p∧¬q` が偽なので、どの割り当てでも両立しません。`p∨q` と `¬p∧¬q` も同じです。

JavaScript の `sat` は変数の数 n に対して `0` から `2^n − 1` までのビット列を割り当てに見立てています。書き方は違いますが意味は同じで、107 件の例で一致を確かめています。

## 語彙から外す式

生成では、トートロジー(どの割り当てでも真)と矛盾式(どの割り当てでも偽)を語彙から除いています。矛盾式と ⊥ はどんな式とも `unsat2` になるので、Board に 1 枚あると何とでも消えてしまい、考える余地が無くなるからです。
