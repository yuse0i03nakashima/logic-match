# 00 全体像

THE TEN(Number Match 自作版)の骨格を使って、「頭を使う」方向に振ったゲームです。タイルの中身を数字から命題論理の式にしました。コードを読む前の見取り図です。

## なぜ論理か

微積のような計算は、一手の判断に数秒以上かかり、しかも正解が一つに決まる操作ばかりで選ぶ余地がありません。命題論理なら、2〜3 変数の式の真偽は数秒で頭の中に描けて、「どの 2 つを組にするか」「どの順に消すか」という判断が残ります。THE TEN の「足して 10」を「合わせて矛盾」に置き換えるだけで、タイルを選ぶ・つながりを見る・消える・連鎖する、という骨格がそのまま使えます。

## 2 つのモード

| | REFUTE | DERIVE |
|---|---|---|
| 1 手 | 2 つの式を選ぶ | 2 つの式を選ぶ(または 1 つを 2 回タップ) |
| 成立の条件 | 合わせて矛盾する(同時に真にできない) | 推論規則が当てはまる |
| 結果 | 2 つが消える。行が空になれば行が消える | 結論の式に合体する(2 つ目の位置に置かれる) |
| Clear | Board が空 | Goal の式が現れる |
| 緊張感 | Chain、ゲージ、FEVER、Heart、GIVE UP(THE TEN と同じ) | 手数(par 以内で ★★★)。UNDO は何度でもできるが手数は戻らない |
| 頭の使い方 | 真理値表を 1 行ずつ思い浮かべる。パターン(`p→q` の否定は `p∧¬q`)を覚えると速い | 数手先を読む。Goal から逆算して、どの前提をどの順で使うか |

REFUTE の例: `p` と `¬p`、`p→q` と `p∧¬q`、`p∨q` と `¬p∧¬q`、`⊥` と何でも。
DERIVE の規則: MP(A と A→B から B)、MT(¬B と A→B から ¬A)、DS(¬A と A∨B から B)、∧I(A と B から A∧B。Goal の一部になるときだけ)、∧E(A∧B を A と B に分ける)、⊥(A と ¬A から ⊥。Goal が ⊥ のときだけ)。

## 位置の条件

THE TEN は本家に合わせて「行の右端と次の行の左端がつながる」という読み順の条件を持っていましたが、格子の見た目と合わず分かりにくい点でした。ここでは「同じ行・列・斜めの一直線上にあり、間がすべて空マス」だけにしています。8 方向の見通し線で、対称で、説明が一文で済みます。

## 式の表し方

ファイルの中では前置記法の ASCII 文字列です。`!` が ¬、`&` が ∧、`|` が ∨、`>` が →、`F` が ⊥。`>p!q` は p→¬q、`!&pq` は ¬(p∧q)。前置記法は括弧が要らず、先頭の 1 文字を見れば構造が決まるので、再帰で読み書きできます(第 5 章の再帰、第 7 章の `data`)。画面に出すときだけ `pretty` が infix に直し、2 項の中の 2 項にだけ括弧を付けます。

## 面の作り方

- REFUTE: Stage の語彙から式を選び、どの式にも矛盾する相手が Board 上にいること、初手で消せる組が 4 つ以上あることを確かめてから、THE TEN と同じ深さ優先探索で「SHUFFLE なしで全消しできる」ことを確認します。タイル数は偶数。
- DERIVE: 前提を乱数で選び、その Stage で許された規則を前向きに適用して導出を作り、最後の式を Goal にします。前提と邪魔タイルを 4×4 に配置し、幅優先探索で Goal までの最短手数(par)を求めます。到達できなければ配置をやり直します。
